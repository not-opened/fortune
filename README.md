# notopened 무료 운세

가입 없이 브라우저에서 바로 확인하는 사주·꿈풀이·MBTI 궁합·12띠/별자리·미래 배우자 카드입니다.

- 라이브: https://notopened.com/fortune/
- 정적 파일로 동작하며, 계산은 모두 브라우저 안에서 이뤄집니다. 입력값은 서버로 전송되지 않습니다.
- 결과는 엔터테인먼트·참고용이며 의학·법률·재무 자문을 대체하지 않습니다.

## 기능

- 사주 오행·올해 운세 6대 영역·꿈풀이 30종·MBTI 16유형 궁합·12띠/별자리 오늘 운세·미래 배우자 카드·궁합 3종.
- 꿈풀이 탭 상단의 인기 키워드 칩(뱀·이빨·돈·물·조상·시험·집·고양이·강아지·돼지)으로 한 번에 풀이를 엽니다.
- 결과 공유는 링크에 입력값을 담아, 다른 브라우저에서 열어도 같은 결과가 다시 계산됩니다(사주 요약·배우자 카드·오늘 운세).
- 하단에 웹 1호 퀴즈(https://notopened.com/quiz/)와 웹 2호 바둑·체스(https://notopened.com/go-chess/) 바로가기가 있습니다.
- 하단 제휴 영역은 쿠팡 파트너스 다이나믹 배너이며, 배너가 로드될 때만 표시됩니다. "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 문구를 함께 표시합니다.
